## 1. 新增系统模块设计

### 1.1 人际关系系统
- **关系类型**：朋友 `friend`、恋人 `lover`、配偶 `spouse`、子女 `child`、仇人 `enemy`。
- **好感度**：0–100。朋友/恋人/配偶/子女初始 60，仇人初始 20；同类型事件会叠加好感（+10/次）。
- **关系生命周期**：结识 → 加深 → 破裂 / 离世（`【关系结束:名字】`）。
- **剧情覆盖**（14 条）：同事变铁哥们、老同学多年重逢、合伙被卷款反目、恋人出轨、自己出轨被抓、异地分手、长期冷战闹离婚、生子后关系变化、孩子青春期叛逆离家、孩子考上名校、父母重病需照顾、父母离世办丧事、借钱不还绝交、与仇人正面斗殴。
- **成就挂钩**：铁哥们（好感≥90）、青梅竹马（18 岁前恋爱）、儿孙满堂（子女≥3）、众叛亲离（仇人≥3）、老友重逢、丧亲之痛、感情破碎。

### 1.2 职业系统
- **岗位池**（20+）：大厂程序员、国企职员、工厂普工、外卖骑手、网约车司机、教师、公务员、汽修工、销售、部门主管、护士、电商运营、主播、作家、快递员、理发师、电焊工、店主……
- **薪资公式**：`月薪 = 岗位基准 × 城市财富上限系数 × (0.7 + 智力/50×0.3) × (1 + 已习得技能数×0.03)`
  → 薪资同时受**城市、技能、智力**影响，符合需求。
- **职业事件**：入职、升职（×1.4 薪资）、失业（被裁员优化）、跳槽（×1.3 薪资）、创业、融资成功、资金链断裂破产、老板跑路欠薪、中年转行摆摊。
- **连带规则**：失业后无年收入；有案底者年收入 ×0.7；创业失败清空职业并触发破产成就。

### 1.3 医疗系统
- **疾病谱**：急性阑尾炎手术、感冒拖成肺炎住院、家族遗传病、心脏支架手术、焦虑症、抑郁症与心理咨询、车祸重伤进 ICU、种植牙、糖尿病、老年髋部骨折卧床。
- **精神疾病**：焦虑症 / 抑郁症独立成事件，代价是「长期花钱治疗 + 压力值下降 + 快乐值缓慢回升」的取舍。
- **引擎级医疗规则（新增）**：健康值 < 50 且现金 ≥ 20000 时，每年自动「就医调养」：花 5000 元 → 健康值 +8、压力 −3（学会 `medical`/`nursing`/`first_aid` 后只需 3000 元）。这让**财富第一次真正能换命**。
- **成就**：手术台归来、久病成医（住院≥3 次）、与遗传病共存、心理重建、ICU 奇迹。

### 1.4 消费购物系统
- **资产类别**：现金、房产、车辆、奢侈品、商业保险、负债（`asset_state` 统一管理）。
- **消费事件**：首付买房、全款提第一辆车、冲动买名牌包、被销售忽悠办大额理财保险、跟风炒币暴雷、旗舰机换代、给父母买按摩椅保健品、装修超预算、朋友借钱不还、老年被推销天价保健品。
- **资产负债管理**：负债每年计息 ×1.05；负债 ≥10 万触发「负债累累」；还清历史债务触发「无债一身轻」；净资产 = 现金 − 负债 + 房产估值（房产按城市系数折算）。

### 1.5 年代时代事件
- **五个年代**：80 / 90 / 00 / 10 / 20 年代，开局先选年代，城市必须在 `eraFactor` 中允许该年代。
- **年代专属事件 16 条**，标题带 `【80年代】` 前缀、desc 带 `【年代:80】` 标记，**只有出生在该年代才会抽到**：
  - 80 年代：粮票换鸡蛋、邻居家黑白电视、单位分房、南下深圳摆摊 / 下海经商
  - 90 年代：录像厅港片、排队买股票认购证、父母双双下岗
  - 00 年代：网吧通宵打传奇、非典停课、淘宝开店
  - 10 年代：智能手机换机潮、网约车外卖大战、售楼处抢房
  - 20 年代：封控核酸长队、直播间爆单、AI 浪潮下的裁员通知
- **成就**：下海经商、下岗再就业、互联网原住民、时代见证者（五个年代事件全部经历）。

### 1.6 犯罪加强系统
- **犯罪链**：盗窃电缆 → 夜市斗殴致伤 → 被捕审讯 → 入狱服刑（`【入狱:3】`，跳过年份、无收入、健康与名声持续损耗）→ 狱中劳动与想家 → 表现良好减刑 → 越狱风险念头 → 刑满释放（`【出狱】`）→ 带着案底求职被拒（`【案底】`）。
- **引擎规则**：罪恶值 ≥55 后每年判定抓捕，概率 `(罪恶值−55)/200`，上限 35%；学会 `law` 降 40%，天赋「法盲」涨 50%、「道德底线高」降 50%。服刑期间罪恶值逐年降解。
- **成就**：锒铛入狱、牢底坐穿（累计刑期≥10 年）、减刑出狱、案底在身、洗心革面（出狱后 10 年罪恶值≤5）、越狱未遂。

### 1.7 宠物完整生命周期
- 收养流浪猫狗（`【宠物:猫】`）→ 生病送医（`【宠物生病】`）→ 繁育一窝幼崽（`【宠物繁育】`）→ 送养幼崽 → 走失贴寻宠启事（`【宠物走失】`）→ 衰老行动迟缓 → 离世（`【宠物离世】`）→ 老年独居养宠作伴。
- 宠物有名字、物种、年龄、健康值、存活/走失状态；`pet_care` 技能降低宠物生病概率。
- **成就**：宠物主人、毛孩子爸妈（收养流浪）、宠物医院常客、毛孩子满堂、回喵星了。

### 1.8 成瘾扩展
- **成瘾类型**：烟瘾、酒瘾、网瘾、赌瘾（引擎对未知成瘾名也兼容，实际出现过「手机」等）。
- **双轨数值**：总属性 `成瘾值`（0–100，影响健康与死亡风险）+ 分类型成瘾值（0–100，用于戒断成就）。
- **事件**：应酬染上烟瘾、下班喝酒解压变酒瘾、通宵刷短视频网瘾、半夜找烟、戒酒失败复饮、去戒瘾所治疗、成瘾导致家庭矛盾、成瘾后体检红灯。
- **引擎规则**：成瘾值 ≥60 时每年 55% 概率强制触发「成瘾发作」事件（咬硬抗：成瘾 −18、压力 +12、健康 −5；立刻满足：成瘾 +15、金钱与健康受损）。抗瘾体质天赋使成瘾上涨减半。
- **成就**：戒烟成功、戒酒成功、网瘾戒断、五毒俱全（四种成瘾同时≥50）、戒断地狱（成瘾值≥80 后成功戒断）。

## 2. 剧情标记语言（Event Tag）

为避免破坏「事件格式与原有模板完全统一」这条硬约束，新增事件**不添加任何新字段**，
所有系统副作用通过写在 `desc` 文本末尾的 `【…】` 标记表达，由引擎解析：

| 标记 | 作用 | 示例 |
| --- | --- | --- |
| `【习得:skillId】` | 永久学会技能 | `【习得:programming】` |
| `【宠物:猫】`/`【宠物:狗】` | 收养宠物 | `【宠物:猫】` |
| `【宠物生病】`/`【宠物走失】`/`【宠物繁育】`/`【宠物离世】` | 宠物生命周期事件 | `【宠物离世】` |
| `【关系:friend:小林】` 等 | 新增/加强关系（friend/lover/spouse/child/enemy） | `【关系:spouse:小雨】` |
| `【关系结束:小林】` | 关系破裂或离世 | `【关系结束:阿哲】` |
| `【职业:程序员】` `【升职】` `【失业】` `【跳槽】` `【创业】` `【破产】` | 职业变动 | `【职业:护士】` |
| `【入狱:3】` `【出狱】` `【案底】` `【减刑】` | 犯罪与牢狱 | `【入狱:5】` |
| `【买房】` `【买车】` `【奢侈品】` `【保险】` `【负债:20000】` `【还债:10000】` | 消费与资产 | `【负债:30000】` |
| `【成瘾:烟瘾】` `【戒断:酒瘾】` | 成瘾与戒断 | `【戒断:酒瘾】` |
| `【年代:80】`（或标题前缀 `【80年代】`） | 年代专属限定 | `【年代:20】` |

**好处**：① 原有 JSON 结构与字段一字不改；② 引擎与数据解耦，后续加系统只要加约定；③ 纯文本，任何编辑器都能改。
`tools/merge-json.js` 会校验所有 `【习得:xxx】` 的 skillId 必须真实存在于 `skills.json`（当前 0 错误 0 警告）。

## 7. 引擎规则清单（第二阶段实现依据）

1. **逐年推进**：年龄 +1 → 自然漂移（幼年成长 / 中年衰退 / 老年加速）→ 自愈与损耗判定 → 城市压力与财富上限修正 → 就医调养 → 债务计息 → 抓捕判定 → 成瘾发作判定 → 事件抽取。
2. **天赋开局生效**：`attrModify` 在角色创建时直接叠加（含负值）。
3. **技能永久生效**：命中相关剧情时按技能累计出成功率加成（每技能 +7%，上限 +35%）；结算时以该概率触发「加成生效」——**好的属性变化 ×1.5、坏的变化 ×0.5**（成瘾值/压力值/罪恶值的方向相反），并在日志与 toast 中标注；同时提供被动收益（健身回血、冥想降压、记账增收、园艺降压、急救降低意外损失……）。
4. **城市生效**：`压力值` 修正初始压力；`财富上限` 系数决定财富上限（300000 × 系数）与年收入软上限。
5. **成就自动监听**：跨轮回永久保存，达成即 toast 提示。
6. **罪恶值与抓捕**：见 1.6。
7. **成瘾发作**：见 1.8。
8. **死亡与轮回**：健康值 ≤0 → 死亡结算；年龄 ≥ 预计寿命 → 寿终正寝（寿命由体质、健康值与天赋计算）；转世继承智力/体质/魅力/运气 各 8%。
9. **金手指**：密码 `208526` 解锁控制台，可改 11 项属性、一键 +10 万财富、回满健康、清空成瘾罪恶、习得全部技能、解锁全部成就；解锁即获得「开挂人生」成就。

> 平衡性说明：为了不让「随机瞎选」的玩家普遍英年早逝，加入了两条正向规则——低健康自愈（健康 <40 每年 +3 / <60 且压力 <60 每年 +2）与就医调养。400 局随机模拟的平均寿命由 29.6 岁提升到 55.7 岁，并出现自然寿终的尾部（见 `tools/test-headless.js` 报告）。

## 8. 玩法增强：主动行动 / 关系互动 / 评分 / 存档 / AI（第二轮迭代）

第一轮的玩法是「被动等事件」，玩久了会变成"点过一年 → 看剧情"。第二轮补的是**玩家的主动权**和**长期目标感**。

### 8.1 主动行动系统（14 种，每岁 1 点行动力）

| 行动 | 分类 | 条件 | 效果（有得有失） |
| --- | --- | --- | --- |
| 加班赚钱 | 赚钱 | 无 | 有职业：+月薪×0.6，压力+6/健康-3/快乐-2；无职业：打零工 +2500~5000，体质-2/压力+4 |
| 看病就医 | 健康 | 现金≥8000 | -8000（有医护技能 -5000），健康+12/体质+1/压力-2 |
| 健身锻炼 | 健康 | 健康≥20 | 体质+2、健康+3（健身技能 +2）、快乐+1、压力-3 |
| 进修学习 | 成长 | 现金≥5000 | -5000，智力+3/压力+3，35% 概率随机习得一个技能 |

### 8.5 AI 剧情接入（可选）
把每年的一条剧情交给大模型**原创**：
- 接口：可配置的 **OpenAI 兼容** `/chat/completions`（默认 DeepSeek 官方端点 + `deepseek-chat`）
- 传输：App 内走壳新增的 **`nativeHttp` POST 原生通道**（绕开 `file://` 的 CORS），浏览器里回退 `fetch`
- 约束：只输出固定结构 JSON，**本地严格校验**（11 项属性齐全、整数、财富 ±30000、其余 ±15、成瘾值/罪恶值 0~20、越界夹取、缺字段补 0、结构不合格整条丢弃）
- 兜底：失败 / 超时 / 玩家点「不等了」→ **立刻用本地 155 条剧情池继续**，游戏永不卡死
- 控制：开关、触发概率（15%/35%/100%）、每世上限（默认 30 次）、起始年龄（默认 6 岁）、超时、失败统计、本世 AI 剧情列表
- 安全：**API Key 只存本机 localStorage 的独立键 `tlai_ai_v1`**，不写进 `app.html`、不随存档导出（自检脚本会断言 `app.html` 内不存在 `sk-` 形式的 Key）

> 详细接入步骤、提示词、成本控制与排错见 **`docs/AI接入说明.md`**。

## 11. 第四轮迭代：职业深度线 + 家庭代际线

前几轮的职业只是「一个岗位名 + 一个月薪数字」，子女只是关系列表里的一个名字。这一轮把两条线都做成**有过程、有阶段、有代价**的系统。

### 11.1 职业深度线（行业阶梯 + 行业景气）

**数据**：`src/career.json`（网页版与 Flutter 版共用）

- **12 个行业**：互联网/IT、国企体制、制造业、教育、医疗、销售商务、餐饮服务、物流配送、金融、传媒自媒体、建筑工程、美业手艺

- 每个行业有**按年代的景气基线**：80 年代没有互联网，00 年代起飞，10 年代是风口，20 年代回落；制造业/建筑业在 20 年代下行

**引擎（每一年自动推进）**

| 环节 | 规则 |
| --- | --- |
| 行业景气 | 向年代基线回归 + 随机游走（±8），范围 5–100 |
| 绩效 | 受智力、技能数、天赋（劳碌命/拖延症/晚熟/夜猫子）、压力、摸鱼影响，0–100 |

## 9. 剧情逻辑规则（年龄纠偏 + 前提校验）

真机试玩发现了两类「剧情不合理」：**7 岁触发早恋叫家长**、**9 岁触发高考/中考压力暴涨**。
根因是原始数据的 `age_range` 写得过宽（例如 `[7,17]` 同时覆盖小学到高中），而约束要求原始 JSON 不能改。

于是新增了一份**两个前端共用**的规则表 `src/age-rules.json`，由引擎在运行时执行（Flutter 版读同一份文件）：

### 9.1 年龄纠偏（只收窄，绝不放大）
按事件全文（标题 + 剧情 + 全部选项）匹配关键词，取交集：

| 规则 | 关键词 | 生效区间 |
| --- | --- | --- |
| 升学考试 | 高考 / 中考 / 升学考试 / 志愿填报 / 复读 | ≥ 14 岁，≤ 20 岁 |
| 中学阶段 | 高三 / 高一 / 高二 / 初三 / 初中 / 高中 | ≥ 12 岁，≤ 20 岁 |
| 成年剧情 | 正式成年 / 成年礼 / 年满18 | ≤ 20 岁 |
| 恋爱 | 早恋 / 情书 / 暗恋 / 初恋 / 表白 | ≥ 12 岁 |
| 烟酒 | 抽烟 / 吸烟 / 烟瘾 / 喝酒 / 酗酒 / 酒瘾 | ≥ 12 岁 |
| 幼儿园 | 幼儿园 / 学前班 / 小红花 | ≤ 8 岁 |
| 子女青春期 | 孩子叛逆 / 孩子青春期 / 子女叛逆 / 孩子离家 | ≥ 32 岁 |

保护措施：
- 规则冲突（算出来 min > max）→ **放弃纠偏**，保留原区间，避免事件永远不出现
- 数据里的上限 `100` 视为 **「终身」→ 110**，否则 101 岁以上会没有任何事件可抽

### 9.3 三级兜底（保证永远不会卡住）
`① 年龄合规 + 前提满足  →  ② 只要求年龄合规  →  ③ 只要求年龄区间匹配`，逐级回退；池子非空才返回，绝不出现「抽不到事件」。

### 9.4 修掉的一个真 bug：转世/放弃本世点击无效
确认弹窗的动作名带命名空间（`ui.doGiveUp`），而弹出的「确定」按钮用 `window['ui.doGiveUp']` 取值 —— 永远取不到，
于是放弃本世、清空存档、解锁全部成就全部报「动作丢失」。现已改为**逐段解析路径并保留 this 上下文**，并加了 4 条回归测试锁死。
