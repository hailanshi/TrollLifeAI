# TrollLifeAI · 傻瓜版打包教程（无需 Mac、无需开发者账号、无需越狱签名）

> 目标：把已经做好的单文件网页游戏，套上极简 WKWebView 壳，用 GitHub 免费 macOS 服务器编译成
> **TrollStore 可直接安装的 `TrollLifeAI.ipa`**（arm64 / iOS 12+ / 未加密 cryptid=0）。

---

## 0. 先弄清三件事

1. **业务 100% 在 `app.html` 里**：双击就能玩，iPhone Safari「添加到主屏幕」还能当 PWA 用。
2. **壳只做容器**：`ios-shell/TrollLifeApp/` 里只有 5 个源文件，负责把 `index.html` 塞进 WKWebView、禁缩放、开一个原生取数通道。**壳里一行业务逻辑都没有**，所以不存在前后端两套逻辑打架的问题。
3. **编译在云端**：Windows 电脑就能操作，GitHub 提供免费 macOS 15 机器跑 `xcodebuild`，产物是 ad-hoc 伪签名的 ipa，TrollStore 装它正好。

---

## 1. 先在本机试玩（30 秒）

- 双击 `app.html` → 浏览器直接开玩。
- 手机测试：把 `app.html` 传到 iPhone，用 Safari 打开 → 分享 → **添加到主屏幕**，就是一个独立图标的全屏 App（PWA 模式）。

---

## 2. 注册 GitHub（已有账号跳到第 3 步）

1. 打开 https://github.com/signup
2. 填邮箱 → 密码 → 用户名 → 邮箱收验证码 → 完成。
3. 建议把仓库设为 **Public（公开）**：编译失败时日志会推到 `debug-log` 分支，公开仓库可以直接看原始链接，排查最快。（Private 也行，就是看日志要登录。）

---

## 3. 建仓库

1. 右上角 `+` → **New repository**
2. Repository name 填 `TrollLifeAI`
3. 选 **Public**（或 Private）
4. **不要**勾选 Add a README / .gitignore / license
5. 点 **Create repository**

---

## 4. 上传文件（最关键的一步）

需要上传的内容（**目录结构不能变**）：

```
TrollLifeAI/                      ← 仓库根目录
├─ app.html                       ← 单文件游戏（业务全部在这里）
├─ assets/json/                   ← 5 份数据（talents/achievements/skills/city/event）
├─ src/                           ← 源码分片（改内容后重新构建用，可不上传）
├─ tools/                         ← 构建与自检脚本（可选）
├─ docs/                          ← 文档（可选）
├─ ios-shell/TrollLifeApp/
│  ├─ main.m
│  ├─ AppDelegate.h / AppDelegate.m
│  ├─ ViewController.h / ViewController.m
│  ├─ Info.plist
│  ├─ project.yml
│  └─ Resources/
│     ├─ index.html               ← 业务 html 的打包副本（= app.html 内容）
│     ├─ AppIcon60x60@2x.png      ← 120×120 不透明图标
│     └─ AppIcon60x60@3x.png      ← 180×180 不透明图标
└─ .github/workflows/build-ipa.yml ← 云端编译脚本
```

两种上传方式，任选其一：

### 方式 A：网页拖拽（最简单）
1. 进入新建的空仓库页面，点 **uploading an existing file**
2. 把 `app.html`、`assets`、`ios-shell`、`.github` 这几个**文件夹整个拖进浏览器窗口**
   （`.github` 是隐藏目录，Windows 资源管理器里需要先勾选「查看 → 隐藏的项目」；如果拖不进去，用方式 B）
3. 下方 Commit message 随便写，点 **Commit changes**

### 方式 B：Git 命令行（推荐，隐藏目录不会漏）
在项目根目录打开 PowerShell：

```powershell
git init
git add .
git commit -m "TrollLifeAI first commit"
git branch -M main
git remote add origin https://github.com/你的用户名/TrollLifeAI.git
git push -u origin main
```

> ⚠️ 检查 `.github/workflows/build-ipa.yml` 确实推上去了：
> 仓库页面上方应出现 **Actions** 标签，点进去能看到 `Build TrollLifeAI IPA` 工作流。

---

## 5. 等 Actions 变绿

1. 点仓库顶部 **Actions**
2. 左侧选 **Build TrollLifeAI IPA**，右侧会有一条正在跑的记录（黄点 → 转圈）
3. 点进去可以看实时日志，重点关注这几步：
   - `Show toolchain`：确认是 **Xcode 16 / macOS 15**
   - `Build app (真实退出码)`：真正编译，失败会在这里红
   - `Verify binary exists (防空壳包)`：确认 `TrollLifeApp.app/TrollLifeApp` 主程序真的存在
   - `Verify IPA contents`：确认 ipa 里同时有主程序、`index.html`、两张图标
4. 全绿（约 3–6 分钟）后，页面底部 **Artifacts** 会出现 `TrollLifeAI-ipa`，点它下载 → 解压得到 `TrollLifeAI.ipa`

---

## 6. 用 TrollStore 安装

1. iPhone 上装好 **TrollStore**（支持的系统自行按 TrollStore 官方方式安装）
2. 把 `TrollLifeAI.ipa` 传到手机（AirDrop / 微信文件 / iCloud 网盘 / 数据线都行）
3. 在「文件」App 里点这个 ipa → 分享 → **用 TrollStore 打开**（或用 TrollStore 的 `+` 选择 ipa 文件）
4. TrollStore 会显示安装进度，完成后桌面出现 **TrollLifeAI** 图标，点开即玩

> 因为是 ad-hoc 伪签名 + TrollStore 永久签名，**不需要 Apple 开发者账号，也不会 7 天掉签**。

## 7. 常见问题排查

| 现象 | 原因与解决 |
| --- | --- |
| Actions 失败在 `Generate Xcode project` | 没装 xcodegen 或 `project.yml` 缩进错了（YAML 必须空格缩进，不能用 Tab） |
| 失败在 `Build app` | 点开日志看 `error:` 行；失败时工作流会把完整 `build.log` 推到 `debug-log` 分支，可直接访问 `https://raw.githubusercontent.com/你的用户名/TrollLifeAI/debug-log/build.log` |
| 装上了但**闪退** | 多半是「空壳包」——主程序没编出来。看 Actions 的 `Verify binary exists` 是否通过；本工作流已强制校验，正常不会出现 |
| 打开是**白屏** | `index.html` 没进 .app。检查 `Verify IPA contents` 步骤；工作流会把 index.html 同时拷到 `.app/index.html` 与 `.app/www/index.html`，壳会按两个路径依次找 |
| 页面上**按钮点不动** | 本项目的动态 DOM 全部用内联 `onclick="window.ui.xxx()"`，且所有处理函数显式挂在 `window` 上；如果你自己加了 `el.onclick = fn` 的写法，在 WKWebView 下就会点不动——改回内联式 |
| 图标是**白块/透明** | 图标必须是不透明方形 PNG。重新生成：`powershell -ExecutionPolicy Bypass -File tools/make-icons.ps1`（脚本用 24bpp 无 Alpha 通道输出，天然不透明） |
| 顶部被刘海挡住 / 底部被手势条挡住 | 页面已用 `env(safe-area-inset-top/bottom)` 留白；不要删掉这两个 padding |
| 老系统（iOS 12–13）上下有黑边 | iOS 14 以下不认 `UILaunchScreen`，属于系统级兼容窗口行为；iOS 14+ 全屏正常。需要 iOS 12/13 全屏可另补 `UILaunchImages` 启动图 |
| 想改剧情/数值 | 改 `assets/json/*.json` → 跑 `node tools/merge-json.js`（合并+校验）→ `node tools/build-html.js`（重新生成 app.html 与壳里的 index.html）→ 提交推送 → 重新跑 Actions |

## 8. AI 剧情与 API Key（安全必读）

游戏内置可选的 AI 剧情：每年按概率让大模型原创一条剧情事件。

- 配置方式：App 内底部 **AI** 页签 → 填接口地址 / 模型 / API Key → **测试连接** → 打开开关
- 默认接口：`https://api.deepseek.com/v1/chat/completions`，默认模型 `deepseek-chat`（任何 OpenAI 兼容网关都能用）
- **API Key 只保存在你手机的本地存储里**：
  - `index.html` / `app.html` 里**没有任何 Key**，你推到 GitHub 的文件天然不含密钥
  - 存档导出也不含 Key
  - 清空存档不会删 Key；要清 Key 用 AI 页的「清除 Key」
- App 内调用走壳里的 `nativeHttp` 原生通道（`NSURLSession`），**不受 `file://` 的 CORS 限制**；
  电脑浏览器里直接打开 `app.html` 时若接口不允许跨域会失败，这属于浏览器策略
- 失败不影响游戏：AI 拿不到结果会自动改用内置的 155 条剧情池

> ⚠️ 唯一要避免的做法：把 Key 硬写进 `app.html` 再推到**公开**仓库。本项目不需要这么做，请保持用界面填写。

## 9. 本地一键重建（改完数据后）

```powershell
# 1) 合并 5 份 JSON（原始内容保留 + 新增追加 + 严格校验，出错会中止）
node tools/merge-json.js

# 2) 生成单文件 app.html，并同步拷贝到 ios-shell/TrollLifeApp/Resources/index.html
node tools/build-html.js

# 3) 语法与交付自检（47 项）
node tools/selfcheck.js

# 4) 无头跑 400 局人生，验证引擎逻辑（无浏览器）
node tools/test-headless.js

# 5) 重新生成图标（一般不用动）
powershell -ExecutionPolicy Bypass -File tools/make-icons.ps1
```

## 10. 关于「本机直接出 ipa」

本机是 **Windows，没有 Xcode / iOS 工具链**，因此**无法在这里直接产出 `.ipa`**——
凡是在 Windows 上「生成」出来的 ipa 一定是假包（没有 arm64 主程序、没有正确签名，装上必闪退）。
本教程给出的路径就是业界通用做法：**在云端 macOS 上编译**。你说一声「帮我跑一遍自检」我也可以随时复核工程完整性。
